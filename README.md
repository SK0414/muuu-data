# muuu-data

전국 한우 1++ 등급(근내지방도 9) A·B·C 경락가격 일별 집계입니다. Muuu 앱이 이 파일을 읽습니다.

- 파일: `dataset.json` (평일 하루 두 번 갱신)
- 출처: 축산물품질평가원 「축산물등급판정정보」 오픈 API, 공공데이터포털 (공공누리 제1유형, 출처표시)
- 조건: 품종 한우, 성별 전체, 전국, 결함 제외 가격
- 당일 값은 다음 날 오전 10시까지 바뀔 수 있습니다.

## 필드

| 키 | 뜻 |
| --- | --- |
| `d` | 경매일 (Asia/Seoul) |
| `g` | 육량 등급 A·B·C |
| `n` | 경락두수 |
| `p` | 평균 경락가 (원/kg) |
| `w` | 거래중량 합계 (kg) |
| `a` | 거래대금 합계 (원) |
| `lo`, `hi` | 최저·최고 경락단가 (원/kg) |
